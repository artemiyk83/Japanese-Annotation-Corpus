# Release checklist

- [ ] Add the final author name(s) and dataset title.
- [ ] Add the dissertation chapter citation.
- [ ] Add the GitHub repository URL and, if available, the archived DOI.
- [ ] Select and add an explicit data license after checking rights in the underlying texts.
- [ ] Confirm that translations and source-text excerpts may be redistributed under the selected terms.
- [ ] Tag the repository release as v1.0 and attach the ZIP archive.
- [ ] Do not edit released files in place; issue a new version with a documented changelog.
